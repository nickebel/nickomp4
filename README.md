# N. — somewhere, not everywhere.

Página pessoal para colocar no campo **Links** do Instagram. A proposta é expandir a atmosfera do perfil com uma breve apresentação, fragmentos visuais e a música do momento — não reunir uma lista de botões.

## Publicar no GitHub Pages

1. Abra **Settings → Pages**.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione a branch `main` e a pasta `/(root)`; salve.
4. O endereço esperado é `https://nickebel.github.io/nickomp4/`.
5. Depois da publicação, coloque esse endereço em **Instagram → Editar perfil → Links → Adicionar link externo**.

## Personalizar

- Instagram: `nicko_mp4` no arquivo `index.html`.
- Textos: altere títulos e parágrafos em `index.html`.
- Foto: substitua `assets/profile.jpg`, mantendo o caminho/nome.
- Música: o link atual pesquisa “Bipolar .diedlonely” no Spotify. Se tiver o endereço exato da faixa, atualize o href em `index.html`.
- Aparência: ajuste `style.css`.

Site estático, sem backend ou dependências.
